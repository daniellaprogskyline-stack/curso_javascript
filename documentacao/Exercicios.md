## Exercícios JavaScript (Parte 1 - 3) - Curso JavaScript

Essas são aulas práticas do curso, a proposta é criar dois sites, um com mudanças de cores dinâmicas de acordo com o tempo (dia, tarde e noite) e outro com imagens de acordo com a idade das pessoas.

Começamos criando a base dos projetos com uma nova pasta com arquivos HTML, CSS e JavaScript, usamos o site pixels.com para pegar imagens grátis na internet, tanto de paisagens simulando a passagem do tempo quanto de pessoas com diferentes idades.
