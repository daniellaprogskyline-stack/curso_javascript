## O que o JavaScript é capaz de fazer? - Curso JavaScript #01


A primeira aula começa com uma explicação sobre o que é o JavaScript e o que ele faz. Nessa aula, como primeiro exemplo prático, ele utiliza o DevTools do Google Chrome para ensinar a como fazer experiências com diversos tipos de sites ao desabilitar o JavaScript (três pontinhos, configurações, desabilitar JavaScript). Ao atualizar a página, conseguimos observar como o JavaScript age dentro dela, notando as diferenças visais causadas pela falta dele. Em seguida, ele utiliza o  youtube como exemplo principal e como mais um exercício para demonstrar que fica inviável utilizá-lo sem a linguagem. Logo após, ele parte para o segundo exercício também utilizando o DevTools, onde ele pede para irmos em console e digitar alguns comandos simples de JavaScript, alterando propriedades da página do googgle como por exemplo a cor do fundo, as cores da escrita "Google", entre outras e deixa claro que apesar de estar mudando visualmente para mim, não muda diretamente para outras pessoas.

A última demonstração que ele faz é no site do G1, onde ele mostra como alterar manchetes e textos, e assim finaliza a primeira aula.
