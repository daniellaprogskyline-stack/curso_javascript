## O que o JavaScript é capaz de fazer? - Curso JavaScript #01

A primeira aula começa com a apresentação do conceito de JavaScript e explica sua importância no funcionamento das páginas web. Para demonstrar isso na prática, o professor utiliza o DevTools do Google Chrome, mostrando como desabilitar o JavaScript por meio das configurações do navegador. Após atualizar algumas páginas, é possível observar diversas diferenças visuais e funcionais, compreendendo melhor o papel da linguagem no desenvolvimento de sites modernos.
O YouTube é utilizado como principal exemplo. Com o JavaScript desativado, várias funcionalidades deixam de funcionar corretamente, tornando o uso da plataforma bastante limitado. Essa demonstração evidencia como a linguagem é essencial para a interação dos usuários com o site.

Em seguida, o professor propõe um segundo exercício utilizando a aba Console do DevTools. Nela, são executados comandos simples de JavaScript para alterar elementos visuais da página do Google, como a cor de fundo e as cores do logotipo. Durante a atividade, é explicado que essas modificações acontecem apenas no navegador do usuário e não alteram o site para as demais pessoas que o acessam.

Por fim, o professor realiza uma demonstração no portal G1, mostrando como é possível modificar manchetes, títulos e textos diretamente pelo navegador. Com esse exemplo, a aula reforça o poder do JavaScript para manipular os elementos de uma página web de forma dinâmica e interativa.
