## Variáveis Compostas - Curso JavaScript #15

Nesta aula, o professor começa a ensinar sobre variáveis compostas*, também conhecidas como arrays ou vetores. Ele explica que, até esse momento do curso, utilizamos apenas variáveis simples, que conseguem armazenar apenas um valor por vez. Quando um novo valor é atribuído, o valor anterior é substituído. 

Já as variáveis compostas permitem armazenar vários valores dentro de uma mesma estrutura, facilitando a organização dos dados e reduzindo a quantidade de código necessária em determinados problemas. 

Para explicar o conceito, o professor utiliza a analogia de um estacionamento. Em vez de criar uma variável para cada vaga, é possível agrupar todas as vagas em uma única estrutura, acessando cada posição por meio de um índice. 

Ele apresenta a definição de um array em JavaScript, mostrando que os elementos são armazenados em posições numeradas, chamadas de índices. É importante lembrar que a contagem sempre começa em 0, e não em 1. 

Além disso, a aula aborda algumas operações básicas com vetores, como:

Exibir todos os elementos do array;
Acessar um elemento específico pelo índice;
Adicionar novos elementos;
Ordenar os valores armazenados;
Percorrer todos os elementos utilizando estruturas de repetição. 

O professor também reforça que um array é formado por vários elementos e que cada elemento possui um valor e uma posição de identificação dentro da estrutura. 

Por fim, ele demonstra como percorrer um vetor utilizando o laço for, exibindo cada posição e seu respectivo valor. Também apresenta formas mais simples e modernas de percorrer arrays em JavaScript, destacando a importância de praticar os exemplos para fixar o conteúdo.
