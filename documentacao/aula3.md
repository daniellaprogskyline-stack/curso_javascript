## Dando os primeiros passos - Curso JavaScript #03
Nessa aula, o professor fala sobre a importância da prática no aprendizado da programação. Ele destaca que apenas assistir às videoaulas não é suficiente para desenvolver habilidades como programador. Segundo ele, é necessário manter uma rotina de estudos que envolva assistir aos conteúdos, fazer anotações, ler documentações, praticar exercícios e persistir diante das dificuldades.

Durante a aula, são apresentadas algumas fontes confiáveis de consulta para quem está aprendendo desenvolvimento web. Entre elas, o professor recomenda o site MDN Web Docs, mantido pela Mozilla, que oferece documentações, referências e guias sobre HTML, CSS e JavaScript. Ele também menciona o site da ECMA International, onde é possível consultar a documentação oficial da especificação ECMAScript, padrão que define o funcionamento da linguagem JavaScript.

Além disso, o professor aborda algumas dúvidas comuns e crenças equivocadas relacionadas à programação, esclarecendo conceitos que costumam gerar insegurança entre iniciantes. Ele reforça que aprender a programar exige dedicação e tempo, sendo normal encontrar dificuldades durante o processo.

Na parte final da aula, é demonstrado o processo de instalação das ferramentas que serão utilizadas ao longo do curso, incluindo o Visual Studio Code (VS Code), que será usado como editor de código, e o Node.js, ambiente que permite executar códigos JavaScript fora do navegador.

Essa aula não possui exercícios.
